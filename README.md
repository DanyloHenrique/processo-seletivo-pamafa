# Pamafa

## Stack do Projeto

Front-End:
- Next.js
- Styled Components

## Como rodar o projeto

Primeiro é necessário clonar o repositório e entrar no diretório do projeto
```bash
git clone https://github.com/DanyloHenrique/processo-seletivo-pamafa.git
cd processo-seletivo-pamafa
```

### Front-End

1. Entrar na pasta front-end
```bash
cd front-end
```

2. Instalar dependências do projeto

```bash
npm install
```
3. Executar o projeto

```bash
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000) no navegador para ver o resultado
